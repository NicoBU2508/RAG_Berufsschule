Der Compiler javac übersetzt den Quellcode einer Datei in Java-Bytecode. Jede in 
einer Datei deklarierte Klasse übersetzt der Compiler in eine eigene Klassendatei.

Bytecode 
Der Bytecode ist in der Informatik eine Sammlung von Befehlen für eine virtuelle 
Maschine. Bei Kompilierung eines Quelltextes mancher Programmiersprachen oder 
Umgebungen – wie beispielsweise Java – wird nicht direkt Maschinencode, sondern 
ein Zwischencode, der Bytecode, erstellt. 
Java Virtual Machine  
Java Virtual Machine (JVM) ist eine Software, die zur Ausführung von Java-
Programmen benötigt wird und Bestandteil der Java Runtime Environment (JRE) ist.

sondern ein natives Programm für die jeweilige Zielplattform.

von einem Interpreter (für jede Zielplattform) individuell angepasst und ausgeführt.

Funktionsweise und Verarbeitung des Codes in Java 
Um ein Programm zu erstellen, wird dies üblicherweise mittels eines Quelltextes 
gemacht. Dazu benötigt man einen Editor, der beispielsweise standardmäßig von 
Windows geliefert oder Notepad++, was weitere Funktionen bietet. Eine Ausführung 
dieses Quelltextes durch den PC ist aber so noch nicht möglich. Bisher schreiben wir 
unsere Programme als Java-Qellcode in der Entwicklungsumgebung Eclipse und 
lassen dann anschließend die Befehle ausführen. Diesen Quellcode selbst kann der 
Computer aber nicht „lesen“, da er nur 0 und 1 kennt. Mit Hilfe des grünen Run-Buttons 
wird also zunächst eine Übersetzung des Quellcodes in eine für den Computer 
verständliche 
Sprache, 
die 
sogenannte 
Maschinensprache/Maschinencode, 
vorgenommen. 
 
Es gibt dabei, je nach gewählter Programmiersprache, Möglichkeiten zur Übersetzung: 
 
Komplette Übersetzung bei der Programmausführung mit einem sogenannten 
Interpreter 
Ein Interpreter übersetzt dabei, während das Programm läuft, den Quelltext in die 
Maschinensprache. Dabei wird jede Zeile abgearbeitet und auf syntaktische Fehler 
geprüft, was unter Umständen sehr lange dauert. 
 
Komplette Übersetzung bei der Programmerstellung mit einem Compiler 
Ein Compiler wandelt im Gegensatz zum Interpreter bereits vor der Laufzeit den 
Quelltext in Maschinenbefehle um. Dies geschieht allerdings ohne die Ausführung der 
Befehle, jedoch mit Überprüfung der Korrektheit der Syntax. 
 
Zweistufe Übersetzung 
1. Übersetzung in einen plattformunabhängigen Bytecode bei der Programmerstellung 
mittels eines Compilers 
2. Übersetzung des plattformunabhängigen Bytecodes bei der Programmausführung 
mittels eines Interpreters 
Der Quelltext wird bei Java in eine Art Zwischencode, den sogenannten Bytecode 
kompiliert. Der Vorteil liegt darin, dass dieser Code für alle Plattformen gleich ist. Der 
jeweilige Interpreter kann dies anschließend auf der gewünschten Plattform ausführen. 
Diese Interpreter werden auch virtuelle Maschinen (JVM) genannt.
```

4.5.3 Konstanten 
Konstanten haben, wie der Name bereits sagt, während der gesamten Ausführung des 
Programms immer einen festen Wert, der nicht geändert werden kann und werden 
vorab definiert. Dabei wird für sie ein Name und ein Datentyp festgelegt. Der Vorteil 
liegt darin, dass sie das Lesen und die Anpassung eines Programms vereinfachen. 
Die Zahl pi wäre ein Beispiel aus der Mathematik. 
Beispiel: 
In der Schnellversand GmbH sollen auf die Selbstkosten grundsätzlich ein 
Gewinnaufschlag in Höhe von 15% aufgeschlagen werden. Da dies häufig eingesetzt 
wird, empfiehlt es sich hier, eine Konstante einzusetzen. Ein weiterer Vorteil liegt 
darin, dass andere Personen erkennen, worum es sich bei dieser Zahl handelt. Des 
Weiteren ist es einfacher, wenn der Gewinnaufschlag verändert werden soll, da dies 
nur einmalig bei der Konstante durchgeführt werden muss. 
4.5.4 Typkompatibilität und Typkonversion  
Einer Variablen kann nur der Wert des Datentyps zugewiesen werden, welchen die 
Variable selbst besitzt bzw. der Wertebereich zulässt. So kann beispielsweise einer 
Variablen, Typ: double, der Wert einer Variablen vom Typ int zugewiesen werden. 
Dies bezeichnet man als Kompatibilität; bei kompatiblen Datentypen wird von Java 
automatisch eine sogenannte implizite Typkonversion durchgeführt. Der Datentyp 
int ist somit kompatibel zum Datentyp double, andersherum jedoch nicht, da der 
Wertebereich dies nicht zulässt. 
Beispiele: 
double seize = 220; 
Obwohl die Zahl ganzzahlig ist, ist die Zuweisung in 
Ordnung, da sie zu den rationalen Zahlen gehört. 
Diese Datentypkonvertierung wird implizit genannt. 
int weight = 3.57; 
Hier erscheint eine Fehlermeldung, da 3,57 keine 
Ganzzahl ist. Es erfolgt hier keine implizite 
Datentypkonvertierung.
```
