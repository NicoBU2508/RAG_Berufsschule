1. Java 
1.1. Vorstellung von Java 
Java ist eine sogenannte objektorientierte Programmiersprache, die sich durch einige 
zentrale Eigenschaften auszeichnet. Diese machen sie universell einsetzbar und für 
die Industrie als robuste Programmiersprache interessant. Da Java objektorientiertes 
Programmieren ermöglicht, können Entwickler moderne und wiederverwertbare 
Softwarekomponenten programmieren. Heute ist Java die Basis sehr erfolgreicher 
Produkte. Dazu zählen Facebook, LinkedIn, Twitter, Amazon, eBay. Auf der Client-
Seite ist Java seltener zu finden, das Spiel Minecraft ist eher eine Ausnahme. 
Ein Java-Programm wird dabei mit einem Text-Editor geschrieben und als Textdatei 
mit der Endung *.java abgespeichert. Man spricht hierbei vom Quellcode oder auch 
Sourcecode. Nachdem der Quellcode eingegeben wurde, übersetzt dies der 
sogenannte Java-Compiler. Dadurch wird ein plattformunabhängiger Zwischencode 
(„Bytecode“), erzeugt. Die Datei, in der der Bytecode gespeichert wird, unterscheidet 
sich von der Quellcode-Datei nur dadurch, dass sie die Endung *.class trägt.  
Der Bytecode hat somit folgende Eigenschaften: 
➔ Er unterscheidet sich nicht für verschiedene Plattformen (bspw. 
Windows/Linux) 
➔ Er kann nicht direkt ausgeführt werden; er benötigt einen Interpreter 
Der Interpreter ist plattformunabhängig und ist in der Lage, den Bytecode auf der 
jeweiligen Plattform wie beispielsweise Windows oder Linux auszuführen. Der Java-
Interpreter wird auch virtuelle Maschine genannt. Daneben existiert noch eine Reihe 
weiterer Begriffe, die im folgenden Kapitel erklärt werden.

Bytecode

Umgebungen – wie beispielsweise Java – wird nicht direkt Maschinencode, sondern 
ein Zwischencode, der Bytecode, erstellt.

sondern ein natives Programm für die jeweilige Zielplattform.

6.1 Unterschied zwischen prozeduraler und objektorientierter Programmierung 
Prozedurale Programmierung zeichnet sich dadurch aus, dass Befehle abgearbeitet 
werden. Dies wurde in den bisher behandelten Themen vorgestellt und vertieft. In 
Bezug auf die alleinige prozedurale Programmierung ergeben sich mehrere Probleme:

überschrieben zu werden. Des Weiteren gab es keine passende Verbindung zwischen
