Compiler
Der Compiler javac übersetzt den Quellcode einer Datei in Java-Bytecode. Jede in
einer Datei deklarierte Klasse übersetzt der Compiler in eine eigene Klassendatei.
Wenn bei einer Klasse (nennen wir sie A) eine Abhängigkeit zu einer anderen Klasse

Bytecode
Der Bytecode ist in der Informatik eine Sammlung von Befehlen für eine virtuelle
Maschine. Bei Kompilierung eines Quelltextes mancher Programmiersprachen oder
Umgebungen – wie beispielsweise Java – wird nicht direkt Maschinencode, sondern
ein Zwischencode, der Bytecode, erstellt.
Java Virtual Machine
Java Virtual Machine (JVM) ist eine Software, die zur Ausführung von Java-

Im Gegensatz zu Java-Programmen selbst ist die JVM nicht plattformunabhängig,

```text
Zusammenfassung der Virtuellen Maschine:
In Java wird durch den Compiler aus dem Quelltext ein Bytecode erstellt. Dieser wird
von einem Interpreter (für jede Zielplattform) individuell angepasst und ausgeführt.
Java Runtime Environment
Die Java Runtime Environment, kurz JRE, wird benötigt, um ein Programm auf einem
Computer ausführen zu können. Darin sind die sogenannte Java Virtual Machine
(JVM) enthalten, welches den für das entsprechende Betriebssystem erzeugten
Java-Bytecode übersetzt.
Funktionsweise und Verarbeitung des Codes in Java
Um ein Programm zu erstellen, wird dies üblicherweise mittels eines Quelltextes
gemacht. Dazu benötigt man einen Editor, der beispielsweise standardmäßig von
Windows geliefert oder Notepad++, was weitere Funktionen bietet. Eine Ausführung
dieses Quelltextes durch den PC ist aber so noch nicht möglich. Bisher schreiben wir
unsere Programme als Java-Qellcode in der Entwicklungsumgebung Eclipse und
lassen dann anschließend die Befehle ausführen. Diesen Quellcode selbst kann der
Computer aber nicht „lesen“, da er nur 0 und 1 kennt. Mit Hilfe des grünen Run-Buttons
wird also zunächst eine Übersetzung des Quellcodes in eine für den Computer
verständliche Sprache, die sogenannte Maschinensprache/Maschinencode,
vorgenommen.
Es gibt dabei, je nach gewählter Programmiersprache, Möglichkeiten zur Übersetzung:
Komplette Übersetzung bei der Programmausführung mit einem sogenannten
Interpreter
Ein Interpreter übersetzt dabei, während das Programm läuft, den Quelltext in die
Maschinensprache. Dabei wird jede Zeile abgearbeitet und auf syntaktische Fehler
geprüft, was unter Umständen sehr lange dauert.
Komplette Übersetzung bei der Programmerstellung mit einem Compiler
Ein Compiler wandelt im Gegensatz zum Interpreter bereits vor der Laufzeit den
Quelltext in Maschinenbefehle um. Dies geschieht allerdings ohne die Ausführung der
Befehle, jedoch mit Überprüfung der Korrektheit der Syntax.
```

#### Extrahierter Originaltext für Suche und KI

```text
public class A2 {
public static void main(String[] args) {
int[] intArray = {1, 5, 3, 7, 2, 9};
Arrays.sort(intArray);
System.out.println(Arrays.toString(intArray));
// Ausgabe: [1, 2, 3, 5, 7, 9]
}
}
Die Klasse java.util.Arrays; enthält verschiedene Methoden, um Arrays zu
manipulieren und zu verändern.
Die sort()-Methode sortiert die Elemente eines Arrays und gibt das Array zurück.
Standardmäßig werden dabei alle Elemente in Strings umgewandelt und dann
miteinander verglichen.
Im obigen Beispiel wurde ein Array vom Datentyp int deklariert und mit Werten befüllt.
Bei der Ausgabe wurde die toString()-Methode der Klasse Arrays verwendet, als
Parameter anschließend unser Array angegeben.
8.5.3 Befüllen von Arrays mit Elementen
Auch das Befüllen von Arrays kann mittels einer Schleife vorgenommen werden,
welche beispielsweise bei 0 startet (i=0). Sie soll solange laufen durchlaufen werden
bis die Abbruchbedingung erreicht ist (z. B. bis ein bestimmter Wert erreicht ist).
Ansonsten soll i nach jedem Durchlauf beispielsweise erhöht werden. Dies ist bisher
aus dem Aufbau der Schleifen bekannt. Dies kann nun also analog bei einem Array
angewandt werden, da dieses ebenfalls einen Index i besitzt, welcher die Position
eines Elementes angibt.
Beispiel:
for (int i = 0; i < 5; i++) {
```

```text
arrayEins[i] = 1; // Jedes Element erhält die Zahl eins.
}
In diesem Beispiel startet die for-Schleife bei i=0 und wird solange durchlaufen, bis i
nicht mehr kleiner als 5 ist. Nach jedem Durchlauf wird es um 1 erhöht. 5 ist dabei die
Länge des Arrays.
Wichtig ist nun zu erkennen, dass im Schleifenrumpf festgelegt wird, dass das Array
an der Stelle i gefüllt wird. Jedes Element erhält nämlich dadurch die Zahl 1
zugewiesen. Es beginnt als erstes damit, dass beim Index 0 die 1 gesetzt wird.
Um nicht jedes Mal bei einer Änderung der Länge des Arrays die Schleifen ändern zu
müssen, welche das Array befüllen oder auch lesen, empfiehlt es sich, auch hier mit
.length zu arbeiten. Dies hilft, vor allem bei komplizierteren Programmen, die
Übersicht zu bewahren und so etwaige Fehlerquellen zu reduzieren.
```
