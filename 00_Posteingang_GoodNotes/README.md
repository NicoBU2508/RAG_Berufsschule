# 📥 Posteingang für neue GoodNotes-Mitschriften

Dieser Ordner ist dein Ablageort für neue oder aktualisierte **GoodNotes-PDFs**. Er ist bewusst von Obsidian Copilot ausgeschlossen, damit ungeprüfte Rohdateien nicht versehentlich indexiert werden.

## So geht es am schnellsten

1. Exportiere deine Mitschrift aus GoodNotes als **PDF** (gerne mit aktivierter Handschrifterkennung/Textschicht, aber auch reine Scans/Handschrift funktionieren).
2. Lege die PDF-Datei hier in `00_Posteingang_GoodNotes/` ab (oder lade sie direkt im Chat hoch).
3. Schreib im Chat einfach: **„Integriere meine neuen GoodNotes-Mitschriften“** (optional mit Fachangabe, z. B. `AE`, `BGWP`, `ITT`, `Deutsch`, `Englisch`, `PuG`, `Religion`).

> [!privacy] Datenschutz
> Lege hier **keine** Notenlisten, Zeugnisse, Zeugnis-Scans oder private Dokumente ab.

Details zum kompletten Ablauf findest du in [[00_WORKFLOW_NEUE_MITSCHRIFTEN|Neue GoodNotes-Mitschriften integrieren]].
