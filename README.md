# RAG_Berufsschule
Ein Wissens- und Lern RAG für die Fachinformatiker-Ausbildung, das Obsidian mit automatisierten Python Scripten mit Goodnotes Verbindet, um automatisiert Mitschriften hochzuladen.
Neue PDF-Mitschriften werden automatisch auf Duplikate geprüft, für KI-Assistenten datenschutzsicher aufbereitet und direkt in 139 Themenbereiche sowie 860 Karteikarten überführt – ergänzt durch einen maßgeschneiderten KI-Lerncoach Skill mit wissenschaftlichen Lernmethoden zur gezielten IHK-Prüfungsvorbereitung.
