# Altklausuren und Lösungen

> [!altklausur] Workflow für spätere Uploads
> 1. PDF der Altklausur nach `06_Altklausuren/AP1` oder `06_Altklausuren/AP2` legen.  
> 2. Lösung direkt daneben ablegen.  
> 3. Für jede Aufgabe eine Analyse-Notiz nach dem Template erstellen.  
> 4. Jede Aufgabe mit mindestens einer Originalquelle und einem Thema verknüpfen.  
> 5. Danach [[Referenzmatrix Altklausuren]] und [[Haeufigkeitsanalyse]] aktualisieren.
